# Account sign-in removed

Sonora 0.8.1 removes the Spotify/Google OAuth adapters, callback handling, client configuration and optional token broker. There is no sign-in setup to complete.

Use [public playlist links](PUBLIC-PLAYLISTS.md), [Spotify ZIP/JSON exports](SPOTIFY-EXPORT.md) or [Google Takeout](IMPORTING.md). Existing imported playlists remain in the local library.

Earlier implementation and validation reports are historical records, not current features.
