Spotify playlist and saved-song import is now available through official account-data ZIP/JSON exports, without OAuth or developer credentials. Select lists, optionally search YouTube for playable versions, and review each match before saving. Exported metadata has no reliable duration, so uncertain recordings are never chosen automatically.

Preserves playlist order, favorites, history and the existing merge-only reimport behavior. Supports split playlist files, saved-song Favorites, offline review, bounded ZIP parsing and cancellation. No account connection or token is retained. Takeout and public YouTube playlist imports continue to work.

Direct Spotify account authorization still requires a registered public client ID and permitted users. Google account import remains experimental and disabled; its documented provider approval/hosting requirements are unresolved. These account flows have not been tested with real accounts. This release adds a working file-transfer route, not an enabled OAuth login.
