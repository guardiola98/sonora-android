Playlists now have a Shuffle button beside Play all. It starts a randomized playback queue while preserving the saved playlist order. Public playlist/album results can also shuffle the tracks loaded so far.

Podcast playback now uses round rewind/forward 10-second controls beside the previous/next episode buttons. Both directions seek exactly ten seconds, including repeated taps, with start/end boundaries handled by Media3. Playback speed remains available below.

Artists search now includes the remote YouTube Music artist catalog, without requiring MusicBrainz enrichment or an account. Tap an artist to search their songs. Ordinary YouTube channels remain separately labeled, and artist names are no longer treated as song-version tags.

Uses the existing persistent signing key and preserves the Room schema, playlists, favorites, history, podcast subscriptions, backups and import flows.
