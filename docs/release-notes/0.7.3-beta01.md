The full player and Up next queue now include a Shuffle up next button. It randomly reorders pending tracks without restarting or interrupting the current track, changing its position, or changing play/pause state. Previously played tracks and saved playlist order stay unchanged.

The button works with music and podcast queues and is enabled when at least two items remain after the current item. Tap again to reshuffle; this is an action, not a persistent shuffle mode. The displayed queue, Next button and restored queue all follow the new order. Radio keeps its existing autoplay setting.

Uses the existing signing key, preserving playlists, favorites, history, podcast progress and backups when updating.
