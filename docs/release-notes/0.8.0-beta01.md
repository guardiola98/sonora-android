Sonora 0.8.0-beta01

Català
- Baixa cançons, llistes i episodis per escoltar-los sense connexió. Gestiona el progrés, les pauses i l’espai des de Biblioteca → Descàrregues. Per defecte, només s’utilitza Wi-Fi sense límit de dades.
- Importa llistes públiques de Spotify i YouTube Music per enllaç, sense configurar cap compte de desenvolupador. Revisa les versions suggerides abans de desar. Spotify pot mostrar només part d’una llista; per completar-la, usa l’exportació ZIP/JSON.
- Interfície en català, castellà i anglés. Tria l’idioma a Quant a Sonora → Idioma de l’app.
- Es conserva el botó aleatori al reproductor i a la cua. L’actualització manté la biblioteca i la clau de signatura habitual.

Castellano
- Descarga canciones, listas y episodios para escucharlos sin conexión. Gestiona las descargas desde Biblioteca → Descargas; solo Wi-Fi sin límite de datos por defecto.
- Importa listas públicas de Spotify y YouTube Music mediante un enlace y revisa las versiones antes de guardar. La página pública de Spotify puede mostrar solo parte de una lista; usa la exportación ZIP/JSON para completarla.
- Interfaz en castellano, catalán e inglés, con selector de idioma en Acerca de Sonora.
- Se mantienen el botón aleatorio del reproductor, la biblioteca y la firma habitual para actualizar sin desinstalar.

English
- Download music, playlists and podcast episodes for offline listening, with progress, pause/resume, retry and storage controls. Unmetered Wi-Fi only by default.
- Import public Spotify and YouTube Music playlist links without OAuth setup. Review suggested playable versions; Spotify's public preview may be incomplete, with ZIP/JSON export available for missing entries.
- English, Spanish and Catalan interface and an in-app language picker. Player/queue shuffle remains available. Same signing key and preserved library for in-place upgrades.
